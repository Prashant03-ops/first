Frequently asked questions

Everything you need to know about the AetherFlow platform, code deployment, and pricing.

AetherFlow is an AI-powered no-code SaaS generator that allows you to build completely functioning web applications by describing them in plain language. Unlike traditional visual builders, AetherFlow writes clean, high-quality production code, structures databases, maps API endpoints, and deploys it on our global cloud network in seconds.

When you describe your app, our AI compilation agent translates your description into structural, logical, and style schemas. It then builds a full relational database, creates API routes, configures user authentication rules, generates a responsive React/Vite frontend UI, and compiles it all. Once successfully tested, the app is built and hosted globally on our edge network.

No coding experience is required! You can build complete apps entirely with English descriptions. However, if you are a developer, AetherFlow serves as an exceptional accelerator. You can write custom code, export the synthesized codebase, edit files manually via our code editor, or link it directly to your GitHub repository.

All apps created on AetherFlow are automatically deployed to our globally-distributed edge CDN network, powered by AWS and Cloudflare. This ensures sub-100ms response times globally. Pro and Enterprise customers can easily hook up custom domain names with automatic SSL renewal.

Absolutely. Security is engineered directly into our schema generation. AetherFlow automatically writes standard Row-Level Security (RLS) rules for your database, uses secure JSON Web Token (JWT) structures for user sessions, and shields your database behind a secure backend API layer. All connections are encrypted via TLS 1.3.

You do! You have 100% intellectual property ownership of your application structure, designs, data schemas, and the compiled code. On the Pro plan, you can export your codebase at any time, host it on your own server, and even license or sell it independently.
